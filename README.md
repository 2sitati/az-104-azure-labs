# az-104-azure-labs


A weekly hands-on lab portfolio built while studying for the Microsoft AZ-104 (Azure Administrator) certification.

Each week focuses on a real Azure administration task — built, tested, documented, and cleaned up in a shared lab environment. The goal is to demonstrate practical understanding, not just screenshots.

**Progression:** Learn → Build → Test → Troubleshoot → Document → Clean up → Share

See [PROGRESS.md](PROGRESS.md) for the full tracker.
